# UHI v6.1: top-N membership robustness (21 Nov 2026, America/El_Salvador)

Script: `analysis/topN_membership_v61.py` (standalone; added in v6.1.1; it does not change UHI code or the released outputs).
Outputs: `tables/v6.1_topN_membership_targets.csv` (per target), `tables/v6.1_topN_membership_counts.csv`, `tables/v6.1_topN_membership_summary.json`. Per-draw matrices (scratch, not shipped): `analysis/_topN_scratch/` by default (`--scratch`).

**Method.** The released CSVs do not store per-draw scores, so the script re-runs the released v6.1 `main` configuration in memory (seed 42, 10,000 draws, about 3 min per threshold) and captures the per-draw UHI matrices. Check: UHI_rank, P_alive, P_top10 and rank_med match the released CSVs to ≤ 1e-16 at both thresholds, so these are the released draws. In each draw, the planets of one facility list (JWST = transiting, ELT/PCS = non-transiting) are ranked by their UHI score. A vetoed draw (score 0) never counts. P(top-N) is the fraction of draws in which the planet is in the top N. The nominal top-N is the published order (UHI_rank). The order by median per-draw rank is also in the files.

**Reading.**
- **Rocky.** Membership is capped by survival: the leading planets have P_alive ≈ 0.4–0.97 (ELT leaders 0.48–0.61). Highest P(top-10): TRAPPIST-1 e 0.62 (JWST, 5σ), Kepler-442 b 0.63 (JWST, 3σ), GJ 273 b 0.55 (ELT). In the draws where a planet survives, the published top-10 is stable, especially for the ELT list (9 of 10 stay in it in ≥ 80% of their surviving draws at 5σ). The top-5 is not stable: positions 3 to 10 swap often.
- **Hycean.** P(top-N) equals P_alive for every listed planet (≤ 0.15). So few Hycean planets survive in any draw that every survivor makes the list. The ranking says nothing beyond survival, which is consistent with marking the branch indicative.
